# Student Placement Dashboard

React + Vite academic project implementing authentication, dashboard analytics, job search/filter, applications, interviews, notifications, profile management, React Router, Context API, responsive design, localStorage and Recharts.

## Run in VS Code
1. Install Node.js LTS.
2. Extract and open this folder in VS Code.
3. Terminal -> `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown by Vite.

Demo login: any valid email + any password, or click **Continue with Demo Account**.
